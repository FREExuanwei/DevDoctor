# DevDoctor v1.2.0 版本说明

Windows 11 x64 · 2026-11-16

## 简体中文与外观

顶部快捷外观、设置、当前主题摘要和辅助技术标签共用同一套中文资源。历史状态、诊断类型、日期、应用生成的项目证据标题和 HTML 可见状态也采用简体中文。产品名、工具名、规则号、技术字段、命令、路径和外部工具原始证据保留其写法，便于核对实际环境和读取旧文件。

| 主题 | 原有设置 ID | 视觉特征 |
|---|---|---|
| 清爽蓝 | `FluentBlue` | 分块方形几何、蓝白与深蓝灰表面 |
| 午夜蓝黑 | `Midnight` | 冷灰与低亮度深色表面、细线装饰 |
| 极光紫青 | `Aurora` | 紫青渐变与波形装饰 |
| 琥珀暖金 | `AmberGold` | 暖金、奶油白与暖深色、同心圆装饰 |
| 绯红曜石 | `CrimsonObsidian` | 石墨与绯红、斜切面装饰 |
| 玫瑰薰衣草 | `RoseLavender` | 粉紫与玫瑰色表面、有机轮廓 |

| 界面风格 | 原有设置 ID | 布局差异 |
|---|---|---|
| 专业标准 | `FluentProfessional` | 标准侧栏、内边距与圆角 |
| 柔和卡片 | `SoftCards` | 较大的圆角和卡片间距、阴影层次 |
| 紧凑高效 | `CompactPro` | 较窄的侧栏、较低的控件和更紧凑的间距 |

浅色、深色、跟随系统继续可选。外观设置即时应用和自动保存。修正了按 Enter 切换主题后的焦点，以及 Windows 高 DPI 与应用缩放叠加时的弹窗大小和定位。

## 搜索、诊断和历史

- 顶部“搜索当前结果”和 Ctrl+K 可按工具、关键词、状态、规则、证据或项目类别搜索。结果可打开并突出精确问题或项目匹配，保留关联模块重测入口。搜索使用现有诊断结果，私有路径和凭据按搜索安全规则处理。
- 在历史原有筛选上加入脱敏文本关键词，支持分页、清空和取消。旧库和旧记录可直接查询。SQLite schema 2、数据格式 1、规则集 2 和报告机器字段沿用。
- 新手说明覆盖 PATH、JDK、Python 虚拟环境、Node 包管理器、.NET SDK 和 CMake。问题详情保留证据、人工操作、风险、恢复步骤和修复后的验证。可复制只读命令并重测关联模块。
- 本次评估后暂缓 DeepSeek，避免增加云端数据传输、密钥管理和使用费用。
