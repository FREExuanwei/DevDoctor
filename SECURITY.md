# Reporting security vulnerabilities / 安全漏洞反馈

## English

If private vulnerability reporting is available for this repository, go to **Security → Advisories → Report a vulnerability** on GitHub. The Security tab may be labeled **Security and quality**. Include the DevDoctor version, affected feature, Windows version, and conditions or steps needed to reproduce the issue. Use synthetic or redacted data in examples. [GitHub guide to private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Open a GitHub issue for general usage questions. Keep real history databases, full diagnostic reports, backups, personal paths, scope keys, and service credentials on your machine.

## 简体中文

如仓库的私密漏洞报告入口可用，请在 GitHub 的 **Security → Advisories → Report a vulnerability** 提交。Security 标签页也可能显示为 **Security and quality**。可以提供 DevDoctor 版本、受影响功能、Windows 版本和可复现条件或步骤。示例使用合成或已脱敏的数据。 [GitHub 私密报告说明](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

一般使用问题可以提交 GitHub Issue。真实的历史数据库、完整诊断报告、备份、个人路径、范围密钥和服务凭据应留在本机。
