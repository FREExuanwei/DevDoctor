DevDoctor v1.2.0 — Windows 11 x64

运行 DevDoctor.exe。本 Release 包已包含 .NET/WPF 运行时，
不依赖 .NET SDK、Visual Studio 或源码目录。

安装版数据：%LOCALAPPDATA%\DevDoctor\Installed
便携版数据：%LOCALAPPDATA%\DevDoctor\Portable\<程序包路径标识>
便携版依靠可执行文件旁的 portable.mode 标记识别，请保留该文件。
两种版本的数据不会自动共享，请通过应用的“备份与恢复”迁移。
数据保存在程序目录之外，因此支持只读程序目录。请在自己控制的位置备份。

升级、卸载与重装保留设置、外观、SQLite 历史、报告及备份。
安装器不提供删除用户数据选项。诊断不自动安装工具链，
不修改 PATH、防火墙、PowerShell 执行策略或系统安全策略。

本包未进行代码签名。Windows 可能显示发布者/SmartScreen 提示。
请保留 Windows 安全功能并核对 SHA256SUMS.txt。

安装器使用 Jordan Russell 和 Martijn Laan 的 Inno Setup
（https://jrsoftware.org/）。原始运行时和安装器许可证、正规简体中文
翻译来源保存在 licenses/ 与 DEPENDENCY-LICENSES.json。
