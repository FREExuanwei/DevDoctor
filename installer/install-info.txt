DevDoctor 1.2.0 — Windows 本地开发环境诊断助手

本安装包包含 Windows x64 应用及 .NET/WPF 运行时。
不需要另装 SDK、Visual Studio、网络服务或管理员账户。

您可以选择安装位置、开始菜单文件夹及是否创建桌面快捷方式。
程序仅登记当前用户的应用与卸载入口，不修改 PATH、防火墙、
Windows 安全策略或开发环境设置。

设置、外观、SQLite 诊断历史、报告与备份保存在独立数据目录：
  %LOCALAPPDATA%\DevDoctor\Installed

升级、卸载与重新安装均保留用户数据；安装器不提供删除用户数据选项。
检测到已有安装时可直接继续升级，无需先卸载。请先在应用中备份并关闭
应用。安装失败时请保存日志、保留数据并重试；强制终止不保证自动回滚。
便携版的数据目录独立；跨版本或跨版本类型迁移请使用“备份与恢复”。

本软件提供诊断与人工建议，不会自动修复环境或安装开发工具。
安装完成后“运行 DevDoctor”默认不勾选，由您主动决定何时启动。

许可与第三方说明：本包包含各运行时组件原始许可证、
DEPENDENCY-LICENSES.json 和 THIRD-PARTY-NOTICES.md。
安装器使用 Jordan Russell 与 Martijn Laan 的 Inno Setup。
正规简体中文翻译的来源及许可证随包放在 licenses 目录中。
本页说明不替代各组件的原始许可条款。

本安装包未进行数字签名。Windows 自身的安全提示由系统控制，
请保留系统安全功能并核对 SHA-256 校验清单。
